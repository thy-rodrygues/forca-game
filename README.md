Um clássico **Jogo da Forca** moderno e interativo desenvolvido em arquivo único, ideal para jogar diretamente no navegador com uma interface limpa e responsiva.

---

## Funcionalidades

- **Interface Moderna & Responsiva**: Estilizada com Tailwind CSS, proporcionando uma experiência agradável em computadores e celulares.
- **Desenho Dinâmico (SVG)**: A forca e o personagem são desenhados progressivamente a cada erro cometido.
- **Teclado Virtual Interativo**: Suporte a cliques na tela e digitação direta pelo teclado físico do computador.
- **Contador de Sequência (*Streak*)**: Acompanhe suas vitórias consecutivas a cada partida.
- **Modais de Fim de Jogo**: Alertas visuais estilizados para vitória ou derrota com a revelação da palavra secreta.

---

## Tecnologias Utilizadas

- **HTML5** (Estruturação)
- **Tailwind CSS v4 via CDN** (Estilização e Design System)
- **JavaScript (Vanilla)** (Lógica do jogo, manipulação de DOM e eventos de teclado)
- **Lucide Icons** (Ícones vetoriais)
